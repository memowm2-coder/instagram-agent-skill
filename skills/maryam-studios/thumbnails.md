# Thumbnails and covers

A thumbnail has one job: stop the thumb. Weak thumbnails are never made, so
the first step is never design. It is asking Maryam what exists.

## Step 1: ask for assets first

Before any concept, send Maryam one batched asset request. Do not design
around assets you are guessing at.

```
ASSETS NEEDED  ·  {{episode}}

  expression   which face, exactly  (e.g. "mouth half open, eyebrows up, eyes on the object")
  pose         body and hands       (e.g. "pointing at the object, top-left")
  angle        camera               (eye level / slightly low / top-down)
  png          cutout needed?       (yes: shot on plain background, hair edges clean)
  clothes      colour and style     (must not clash with the show's paper and accent)
  props        what she holds       (e.g. "boarding pass", "empty coffee cup")
  background   what we build vs shoot
  existing     reuse from the library? (list file names if yes)

  shoot spec:  vertical, 4K if possible, soft key light from the left,
               3 frames per expression, plain light background for cutting.
```

Ask only for what the concept actually needs. If an existing PNG works, say so.

## Step 2: the concept

Give three concepts, pick one, say why.

For each:

```
CONCEPT A  ·  "{{name}}"
  idea:        one sentence
  layout:      what is where (Maryam cutout left third, object centre, word top)
  typography:  the 1-3 Arabic words on it, font, size, which word is majd red
  colour:      show paper + accent
  why it stops: the specific curiosity gap
```

## Step 3: production notes

For the chosen concept:

- **Photoshop notes:** layer order, paper texture overlay, cutout border
  (thick off-white, soft shadow), grain amount, where the tape goes, the
  stamp position, export 1080x1920 with the key content inside the central
  3:4 crop for the grid.
- **AI prompt:** for backgrounds, textures and props only. Never generate
  Maryam's face or body; she is always real photography. Write the prompt in
  English, describe paper collage / editorial style, the palette hex values,
  and "no text" (type is set by hand in Photoshop, Arabic AI text is unusable).

## Rules

- 1 to 3 words of Arabic, never a sentence.
- مريم هاكس and بكل بساطة: Maryam's face is on every thumbnail, in the same
  cutout style, so the grid becomes a wall of one recognisable person.
- غريب عجيب: the episode is voice and motion graphics only. Whether the cover
  carries her cutout is Maryam's decision (open). Until she decides, the
  cover is pure collage: the archive card, one object, one word, the red stamp.
- The thumbnail asks the question; it never answers it.
- Readable at 25% size. Check it at that size before approving.
- Each show is recognisable on the grid by its paper colour alone.
